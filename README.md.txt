# Курсовий проєкт

Студент: Артьомов Артемій Ігорович

Варіант №1 | Маркетплейс для продажу товарів

Файли проєкту знаходяться на гілці master

Для запуску проєкту локально потрібно:

1. Відкрити дві консолі.
2. В одній консолі зайти в директорію з API, в другій в директорію з frontend(cd path).
3. Для API ввести "dotnet run", для фронтенду ввести "npm run dev".
